# SB-06F — Shared character guidance
Extends playful speech to tutorial, adaptive hints, manual mission briefing, build equipment guidance and campaign victory. Tutorial uses action-specific phrases; Junior retains guided auto narration, otherwise Read Aloud controls automatic tutorial/hint/victory audio. Mission and build buttons are manual to avoid competing voices. Mute and voice volume respected. Shared voice button and ownership-aware cancellation; stop narration on new mission and simulation start. No external audio provider, recorded voices, new save fields or production release. Physical speech/touch testing required, including portrait HUD space, browser activation, and competing existing nonverbal robot cues.
