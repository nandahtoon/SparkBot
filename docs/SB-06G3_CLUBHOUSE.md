# SB-06G3 — Interactive 3D Clubhouse
Adds an actual low-poly Three.js arcade room with seven game-specific cabinets and an animated robot mascot using the current character accent. Accessible projected HTML buttons call the existing game selection handler; no duplicate reward or progress logic. Existing 2D game cards remain visible and playable, and a 2D/3D toggle or WebGL failure lets the player skip rendering. The room mounts only in the hub; renderer/disposable geometry/materials and animation frame are cleaned up on exit, context failure and mode toggle. Pixel ratio capped at 1.25, animation renders at up to 24 FPS, hidden tab skips drawing, reduced motion uses static scene. All seven existing games retained; no new mini-game mechanics. This is a selectable room, not free robot walking or a world-streaming system. The main game's separate renderer may still be active; real-device GPU load, touch targets, overlapping projected buttons, audio balance and WebGL context recovery require physical acceptance. Stable V0.3 remains unchanged. Next SB-06G4 interactive world map and transitions.
