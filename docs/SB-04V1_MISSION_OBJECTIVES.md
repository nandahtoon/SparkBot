# SB-04V1 — Mission objective engine
Implements typed optional objective for new authored missions: delivery, collection, power, repair. Default existing 20 levels still require route and optics; existing debug path unchanged. Collection checks the count at the station, rejects invalid thresholds and fails if a crystal was skipped. Non-power objectives bypass optics, explicit power requires all cores. Code dock presents objective and actual step crystal count plus retry feedback. No new mission is enabled in this increment. All objectives still use legacy track and front laser hardware readiness; separate work needed to make delivery/repair mechanics more distinct, add survey/turns/current physics, new hardware and objective-aware hints/solvers. Repair currently uses a route goal; broken starter program and differentiated gameplay fixtures belong to SB-04V2. Do not equate route-only repair with actual diagnostic mechanic. Save schema unchanged, no release or main merge. Stable V0.2 remains the published baseline.
