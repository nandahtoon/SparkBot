# SB-06G — Living worlds, soundscapes and connected missions (increment 1)
Adds locally synthesized original melodic loops and soft environmental noise beds by scene, separate persisted music/environment volume sliders, existing master mute, pause/hidden-tab stop, narration ducking. Starts after user audio unlock, no external audio or recordings. A reduced-motion-aware animated 2D Game Room clubhouse banner and greeting, actual next mission route cards on map/victory/room, and non-traversable miniature next-route hologram beside the current gate. Ocean ripples and landmarks animate gently; no changes to route collision or command semantics. All existing mini-games remain. Actual 3D world streaming, physically continuous routes, fully distinct chapter environments/rooms and professionally recorded character voices are not yet implemented. Procedural ambience is stylized, not authentic wildlife/field recordings. Device audio balance, autoplay, loop transitions, route visibility and FPS need manual QA. No stable merge/promotion. Next increment: chapter-specific environment geometry and next-route transitions, richer character voice and sound design, device acceptance.
